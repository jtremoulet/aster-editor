Rapport d’audit technique

Application de gestion des adhérents — version 2.4

1. Contexte

Ce document présente les résultats de l’audit réalisé du 3 au 14 mars 2026. Il couvre le code, l’infrastructure et les pratiques de l’équipe1. Les références sont disponibles sur l’espace projet.

1.1 Périmètre

  • Front Angular 19, 42 composants

    • Formulaires réactifs

      • Validation côté client uniquement

    • Internationalisation partielle

  • API NestJS, 18 modules

  • Base PostgreSQL 16

1.2 Méthode

  1. Revue de code statique

    1. Analyse des dépendances

      1. Recherche de vulnérabilités connues

      2. Vérification des licences

    2. Lecture des modules critiques

  2. Tests de charge

  3. Entretiens avec l’équipe

2. Constats

Le niveau général est satisfaisant, avec trois points bloquants et une dette modérée importante sur les tests. Taux de couverture : 41 %2.
